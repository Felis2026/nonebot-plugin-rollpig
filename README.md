# nonebot-plugin-rollpig 已迁移

> **本仓库不再作为 Felis 版 RollPig 的主开发仓库。**
> 新功能、修复、发布与文档维护已经迁移到独立项目：
>
> ## 👉 [Felis2026/nonebot-plugin-rollpig-plus](https://github.com/Felis2026/nonebot-plugin-rollpig-plus)

## 现在应该去哪里？

| 你的需求 | 推荐项目 |
| --- | --- |
| 想使用 Felis 维护的拓展版，包含图鉴成长、AI 烤猪、云端资源同步等功能 | [nonebot-plugin-rollpig-plus](https://github.com/Felis2026/nonebot-plugin-rollpig-plus) |
| 想使用更轻量、贴近原始玩法的原版插件 | [Bearlele/nonebot-plugin-rollpig](https://github.com/Bearlele/nonebot-plugin-rollpig) |
| 想查看本仓库迁移前的历史说明 | [README.legacy.md](./README.legacy.md) |

## 仓库状态

- 本仓库仅作为历史留存与迁移指引。
- 后续 Felis 版功能开发、版本发布、安装说明、配置说明都以 `nonebot-plugin-rollpig-plus` 为准。
- 本仓库未来可能只保留用于向上游原版提交 bugfix 的干净分支，不再承载拓展版开发主线。

## 安装增强版

如果你原本是冲着 PLUS 版拓展功能来的，请改用新包：

```bash
pip install -U nonebot-plugin-rollpig-plus
```

NoneBot 插件配置与完整说明请查看新仓库：

- [nonebot-plugin-rollpig-plus README](https://github.com/Felis2026/nonebot-plugin-rollpig-plus#readme)
